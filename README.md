# Portafolio — Carlos “El Rulo” Fernández

Pequeño portafolio web para mostrar servicios y contacto del taller. Se puede abrir directamente con el navegador (no requiere servidor).

Estructura:

- index.html — página principal
- css/styles.css — estilos
- js/main.js — interacciones (copiar teléfono, lightbox, menú móvil)
- images/ — SVGs placeholder que podés reemplazar por fotos reales

Cómo abrir:

1. Abrir `index.html` con el navegador (doble clic o "Abrir con" -> navegador).

Siguientes pasos recomendados:

- Reemplazar los archivos en `images/` por fotos reales del taller y los trabajos.
- Ajustar textos o precios si querés mostrar tarifas.
- Si querés formulario real, conectar la `form` a un servicio (email, WhatsApp API o backend simple).
